========================================================================
                      CUSTOM APP LOGO FOLDER
========================================================================

How to use your own custom logo for SnapSave:

1. Drop your logo image file into this exact folder:
   mobile_app/assets/logo/

2. Name your file any of the following:
   - app_logo.png
   - app_logo.jpg
   - logo.png
   - logo.jpg

3. The app automatically loads your image:
   - On the 2-second Splash Screen (which moves & launches into the app)
   - In the top header bar of the main screen

If this folder is empty or the file is missing, the app seamlessly uses
the built-in futuristic vector gradient logo without any errors.
